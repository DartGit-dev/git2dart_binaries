#12 · CI artifact export layout leaves platform test payloads unavailable

Context: validation-release-assembly · Severity: high · Priority: P0

Confirmed cause

Each test-delivery artifact uploads export/** together with a sibling provenance file. GitHub retains export/ in the archive. Consumer jobs download into platform roots but their loaders expect the libraries directly there.

Strategy

Direct correction: upload only native files under export/ for cross-job test delivery. Build-time provenance stays in its existing location for release-proof checks.

Correction change set

CHGTypeArtifactPurpose
CHG-001configurationbuild-android, build-linux, build-macos, build-windows actions; build_package workflowRemove sibling provenance paths from test-delivery artifact uploads.
CHG-002testtest/native_cache_action_contract_test.dartAssert test artifacts carry only export contents.

Planned proof

Run the static contract test and repository checks locally, then push the corrective commit and require a green GitHub Build package run.

Risk

Medium: the contract is cross-platform. Scope excludes native compilation and release-proof provenance validation.
