# Behavior-Proving Tests, Flows

## F1 — Guarded fixture/process

1. Create a unique temporary root with an expected prefix. 🟢
2. Reject file paths escaping that root. 🟢
3. Run child commands with explicit environment and timeout. 🟢
4. Sanitize root paths in captured stdout/stderr and clean recursively. 🟢

## F2 — W001-W003 runtime evidence

1. W001 performs exact above-uint32 set/get/restore on a declared 64-bit payload. 🟢
2. W002 uses fresh processes for loader failure and host-independent Android plan. 🟢
3. W003 injects directory/asset/write operations and observes cache/retry transitions. 🟢
4. Any missing native/device prerequisite remains unavailable, not pass. 🟢

## F3 — W004-W006 supply/policy evidence

1. W004 creates/validates artifact manifests/proofs across independent corruption cases. 🟢 local
2. W005 injects a binding/payload into a disposable bundle and checks exact consumer resolution. 🟢 local mechanism
3. W006 parses AST/workflow facts and evaluates validation/publication reachability. 🟢 local structural
4. Hosted and registry claims wait for actual current run/outcome records. 🔴
